# 📁 Kuramoto Benchmark Suite - Data Directory

This directory stores sample datasets, benchmark outputs, and simulation artifacts produced by the `kuramoto` CLI and Python API.

---

## 🗂️ Directory Structure

- `data/examples/`: Starter demo datasets used for quick testing, tutorials, and CLI visual commands (`kuramoto datasetforbeginners`, `kuramoto network`, `kuramoto time`).
  - `demo_dataset.npz`: Complete Kuramoto trajectory on a small-world topology with 25 oscillators.
  - `small_demo.npz`: Lightweight 10-oscillator demo dataset.
- `data/benchmark/`: Output arrays and configuration manifests generated during solver performance and scaling sweeps.
  - `euler.npz`, `rotor.npz`, `rk45.npz`: Output trajectories across solvers.
  - `rotor_dt_*.npz`: Time-step convergence sweep results for Geometric Algebra rotor solvers.
  - `config.json`, `sweep_config.json`: Configuration specifications for reproducible benchmark runs.
  - `rigorous_results.json`: Precision and timing benchmarks comparing classical ODE, GA rotor, and quantum solvers.

---

## 💾 Dataset Format (`.npz`)

Datasets generated by `kuramoto generate` or `kuramoto.api.generate_kuramoto_dataset` contain the following standard NumPy array keys:

| Key | Shape | Type | Description |
| :--- | :--- | :--- | :--- |
| `t` | `(T,)` | `float64` | Integration time steps |
| `theta` | `(T, N)` | `float64` | Oscillator phase trajectories $\theta_i(t) \in [-\pi, \pi]$ |
| `omega` | `(N,)` | `float64` | Natural intrinsic frequencies $\omega_i$ |
| `order_parameter` | `(T,)` | `float64` | Global Kuramoto synchronization metric $r(t) = \frac{1}{N}\left\|\sum_j e^{i\theta_j(t)}\right\|$ |
| `psi` | `(T,)` | `float64` | Mean phase $\psi(t)$ |
| `adjacency` | `(N, N)` | `float64` | Network coupling adjacency matrix $A_{ij}$ |

If `--track-symmetries` is enabled, Lie-algebraic symmetry metrics (`global_phase_drift`, `energy_drift`, `rotor_norm_error`) are also logged alongside a companion `.json` metadata file.
